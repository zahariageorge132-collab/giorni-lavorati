# Giorni lavorati

Web app per segnare i giorni lavorati (e ferie, malattia, permessi, Abort).
Funziona anche offline; i dati restano salvati sul telefono.

**Su iPhone:** apri il link di GitHub Pages in Safari → Condividi → "Aggiungi alla schermata Home".

Usa "Salva backup" ogni tanto per tenere una copia dei dati.
